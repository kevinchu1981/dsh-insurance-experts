## 样例 A：分红型增额终身寿 · 定价片段（示意）

```python
from life_pricing_model import PricingAssumptions, solve_premium, net_premium
a = PricingAssumptions(sum_assured=1000, pricing_interest=0.020, sex='male',
                       premium_term=5, issue_age=40,
                       table_version="auto", evaluation_date="2026-06-30")
prem_per_k = solve_premium(a)   # 每千元基本保额年交毛保费
net = net_premium(a)            # 净均衡保费
```

**输出要点**
- 费率锚定：40 岁男、5 年交、每千元基本保额年交 ≈ **¥220**（贴近市场真实量级）
- 保证现金价值按「基本保额比例」建模，与条款年度保额公式严格一致
- 分红按账户法：红利 = (准备金+保费) × max(投资−预定利率,0) × 70%

## 样例 C：偿二代二期准备金评估（BEL+RM）

```python
from reserve_valuation_model import ValuationAssumptions, run_reserve_valuation, adequacy_diagnosis
a = ValuationAssumptions(issue_age=40, sex="male", policy_term=None, premium_term=20,
                         product_type="traditional", pricing_interest=0.025, sum_assured=100_000)
res = run_reserve_valuation(a)
diag = adequacy_diagnosis(a, res, asset_yield=0.040)
print(f"利差损缺口峰值(第{diag['peak_t']}年): {diag['peak_gap']:,.2f}")
```

**输出要点**
- 准备金 = 最优估计 BEL + 风险边际 RM（资本成本法 CoC=6%）
- 自动输出利差损诊断（评估利率 − 预定利率缺口）
